# A FLOOR UNDER EVERY PLANTED FLAW CLASS.
#
# Track A built this after discovering a harness defect that quietly cut
# detection to a sixth with every lane green, and a drop from 504 of 1000 to 82
# must break the build rather than appear in a report nobody diffs. This is that
# construct with KILL POINTS substituted for seeds.
#
# THREE BOUNDS, BECAUSE THEY DEGRADE INDEPENDENTLY. Track A lost M19 to a
# count-based floor that could not see a seeds-to-detection regression: a class
# can hold its RATE while its first detection moves far later in the space, and
# how early is what decides whether a cheaper sweep would ever reach it.
#
# B2 ADDED THE THIRD, and it is the reverse failure. A rate is a fraction, and
# B2 changed its DENOMINATOR without changing any class's power: the manifest
# added Env calls, so the sweep visits 300 kill points where it visited 175, and
# every added one is a point at which these classes are not detectable. Every
# rate fell. Not one detection count did. A lane that broke the build on that
# would be reporting arithmetic as a regression -- and a maintainer who then
# lowered the rate floor would have lowered it for the wrong reason and lost the
# bound for the right one.
#
# So: the COUNT is immune to the denominator and blind to per-point dilution;
# the RATE is the reverse; the CEILING is blind to both and sees only how early.
#
# FLOORS WITH MARGIN, NEVER EXACT VALUES. The sweep is deterministic, so exact
# assertions are possible and are deliberately not used: they fail on any benign
# change -- one more Env call, one more key in the workload -- and a lane that
# cries wolf is a lane people delete. A floor passes drift and fails a collapse.
#
# Format:
#   <class> | <rate floor, per mille> | <kill-point ceiling> | <measurement>
#           | <reasoning> | <regime> | <detection-count floor>
#
# THE REGIME COLUMN IS NOT OPTIONAL DECORATION. Section 8.4: a number measured
# at non-default caps never aggregates with a default-cap number. `default` is
# the caps as shipped -- no flush occurs, so it is the direct successor of the
# sweep B1's floors were measured against. `flush` sets a low threshold and adds
# a workload tail that crosses it, and is the only regime in which the flush
# path has kill points at all. An absent column means default.
#
# A class the sweep cannot reach carries a SPLIT LABEL in the rate column --
# covered-by: <instrument> -- naming what catches it instead. Not a silent zero.
# An exempt class is still listed: a class missing from this file is a class
# with no standing measurement, which is how a bug class drifts back into being
# uncatchable one flaw at a time.
